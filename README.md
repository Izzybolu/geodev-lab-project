# **Settlements at Risk: Mapping Watercourse Proximity in Ibadan North-East**

This spatial analysis identifies flood-exposed infrastructure in Ibadan North-East LGA to help urban planners, emergency responders, and policymakers manage hydrological risks.

**GeoDev Lab Africa, Cohort One | Israel ODETOLA**

---

## The question

> Which settlements in Ibadan North-East LGA sit in low-lying areas within 100m of the existing watercourses?
