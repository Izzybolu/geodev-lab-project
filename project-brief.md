# My project brief

## The question

Which settlements in Ibadan North-East LGA sit in low-lying areas within 500m from the existing watercourses?

## The data I need:

- Ibadan North-East LGA boundary shapefile - QuickOSM Plugin in QGIS (admin_level = 6)

- Settlement extents - GRID3 - https://data.grid3.org/datasets/GRID3::grid3-nga-settlement-extents-v4-1/

- Watercourses in Ibadan North-East LGA - QuickOSM Plugin in QGIS (Waterway = yes)

- Elevation data - Copernicus DEM 30m - https://portal.opentopography.org/raster?opentopoID=OTSDEM.032021.4326.3
